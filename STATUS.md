# STATUS — rhetoric-strikes
Обновлено: 2026-11-02 (сессия: клон/огляд leadlag, ключ Anthropic подключён; по чатам до 2026-10-30 — уточнить у Олексія)

## Цель
Проверить, опережает ли публичная риторика удары (на примере Харькова) и вести антикоррупционный граф по украинским судам, компаниям и публичным лицам.

## Сделано
- Сбор Telegram: 70+ каналов без ключей (t.me/s), возобновляемый сбор (`--before-id`).
- БД Neon (Postgres); извлечение признаков: правила + LLM (по умолчанию Gemini, Haiku по запросу).
- Фреймворк lead-lag: перестановочные тесты, expanding-window out-of-sample логистика, block-bootstrap CI.
- Веб `rhetoric-graph.vercel.app`: граф сущностей, чат, вкладка fact-check, прогноз v5 (#105).
- DuckDB/Parquet «data lake» из дампов data.gov.ua (ночная пересборка, GitHub Release): запросы UA-плеча ~3 мин → ~1 мин; офлайн-загрузка через `inbox/`.
- Тесты 1–4b: `docs/leadlag_results_2026-10-18.md` (включая запуски 19.10: январский бэкфил, LLM-метки через e5-small на 100% покрытии).
- 2026-11-02: репозиторий `neo4graph` на месте (`/home/user/neo4graph`), ветка `claude/new-session-xdbu2j` чистая; проведён огляд результатов lead-lag.

## Ключевые выводы (не пересматривать без новых данных)
- Тест 1: `tgt_ru` (RU-посты с назначением цели) r=+0.30 при лаге 1 проходит перестановки, но обратное направление сильнее (idx(t-1) → tgt_ru(t), r=+0.43). Out-of-sample прироста почти нет (RMSE 0.663→0.653, CI исключает 0). Нестабильно по половинам выборки. Предзафиксированный критерий не выполнен.
- Тест 2 (ракеты + КАБ, бинарный «ракетный день»): `thr_ru`/`l2_ru` дают +0.02…0.03 AUC к базе 0.683–0.685, CI касается нуля. Лучший результат, но пока не подтверждён.
- Тест 3 / 3b: LLM-уточнённые доли не добавляют силы сверх регекс-доли на полном покрытии (+0.015…0.019 AUC, CI через 0). Вывод: сигнал в объёме «угрожающей» риторики за день, а не в том, какие посты модель считает реальными угрозами. Регекс-доля `thr_ru`/`l2_ru` остаётся рабочим признаком.
- Тест 4 (Witkoff/Kushner): 4 из 10 сплесков → массированный удар на следующий день (p≈0.04, лаг 1, лучший из 5 лагов, без поправки на множественность). Сплески апр.–июн. в основном про Иран (Исламабад), а не про Украину. Контроль «переговоры вообще» ничего не даёт.
- Звонки Путин–Трамп (n=5, Ushakov-readouts 04-29, 06-14, 07-04, 09-08, 10-09): в пределах 2 дней 2/5 (случайно 0.22), в пределах 5 дней 4/5 (p≈0.2). Только наблюдение.
- Визиты 22.01 (Москва) и 05–06.09 (Москва, Киев): тишина в дни визита, затем комбинированный удар в пределах двух дней. Два случая, n=2.
- Механизм не определён: «удар как ответ на переговоры», «переговоры назначены на ожидаемый удар» и «общий третий фактор» пока не различимы.

## Решения
- Gemini по умолчанию вместо Anthropic API (корпоративный ключ отозван на лимите $10; ключ компании отключён до выгрузки батча — 5.5k из 26.8k меток).
- Полное покрытие меток — через открытые эмбеддинги `multilingual-e5-small` + классификатор (`src/embed_labels.py`), без оплаты. LLM-разметку дальше не покупаем, пока тест не покажет, что она нужна.
- Haiku с extended thinking: токены размышления идут в max_tokens — ставить высокий лимит.
- Реестры только с локального UA worker.
- Ключ Anthropic подключён Олексієм, но в сессии облака ещё не виден. Нужна переменная `ANTHROPIC_API_KEY` в настройках окружения и новая сессия. Использовать только по явной просьбе.
