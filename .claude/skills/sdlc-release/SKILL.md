# /sdlc-release — прод

1. Знайди відкритий PR цієї фічі. Перевір: превʼю зібралось, звіти tester / reviewer / design-auditor без блокерів.
2. Покажи власнику підсумок у 3–5 рядках і спитай: «зливаю в main?». Без «так» — стоп.
3. Злий (`gh pr merge --squash`). Запобіжник sdlc ще раз попросить підтвердження — це нормально.
4. Дочекайся продакшен-деплою (Vercel MCP: стан READY), відкрий продакшен-адресу, перевір ключові сторінки й консоль на помилки.
5. Щось зламалось — запропонуй відкат (Vercel rollback або revert-коміт) і чекай рішення.
6. Допиши в спеку `Випущено <дата>, <адреса>`.
