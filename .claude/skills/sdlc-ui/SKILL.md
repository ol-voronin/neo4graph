# /sdlc-ui — дизайн

Власник — досвідчений дизайнер. Ти пропонуєш, він вирішує.

1. Прочитай спеку й знайди дизайн-систему проєкту (токени в коді, бібліотека Figma, `design.md` поверху).
2. Figma: перед записом у файл виклич `figma:figma-use`, для цілих екранів — `figma:figma-generate-design`. Компоненти й змінні беруться з бібліотеки, не хардкодом.
3. Дай 2–3 варіанти, якщо рішення неочевидне; кожен з одним реченням «чим цей кращий».
4. Опиши стани: порожній, завантаження, помилка, довгий текст, мобільна ширина.
5. AI-функція — виклич `ai-ux-design-advisor` (довіра, розкриття ІІ, людина в контурі).
6. Після вибору власника допиши в спеку посилання на макет і рішення.
