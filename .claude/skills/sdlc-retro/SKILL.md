# /sdlc-retro — розбір

Запускає власник, приблизно раз на два тижні. Не за розкладом.

1. Збери сигнали: останні PR (`gh pr list --state all --limit 20`), коментарі ревʼю, повтори в /sdlc-ship, що власник виправляв руками.
2. Знайди патерни: помилка, що трапилась двічі, — кандидат у правило.
3. Для кожного патерну запропонуй **одну** зміну в найвужчому місці:
   - факт про проєкт → `CLAUDE.md` цього проєкту
   - як виконувати етап → відповідний скіл sdlc
   - поведінка агента → його файл у `plugins/sdlc/agents/`
4. Новий агент — лише якщо та сама окрема робота повторилась 3+ рази й не вміщається в наявні.
5. Покажи список змін і чекай «так» на кожну. Зміни — окремим PR.
